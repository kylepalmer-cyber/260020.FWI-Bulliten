How Publishing Works

This editor can publish directly when an authorized GitHub token is pasted in. The token is used only for that click and is not saved by this page.

  1. Edit the fields below.
  2. Paste the publish token.
  3. Click Publish to GitHub.
  4. Wait briefly for Pages to update.
